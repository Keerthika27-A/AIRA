# Multi-source Collection Architecture

Planned adapters: IndiGo, Air India, Air India Express, Akasa Air, SpiceJet, MakeMyTrip, Yatra, EaseMyTrip, Cleartrip, Ixigo and Goibibo.

Before enabling any live adapter, confirm a permitted access method. Apply rate limits and do not bypass CAPTCHAs, anti-bot systems or access controls. Blocked sources should be logged and skipped.
